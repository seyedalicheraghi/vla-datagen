# Drone scene previews

Images rendered offline with Mitsuba 3 (`scripts/drone_scene/preview.py`, `render_flight.py`) from the same USD
scene Isaac Sim loads. They were made on the cloud machine of the Claude Code session, so they are
collected here to be downloadable.

- `v1_*` to `v4_*`: the scene at each improvement round (demo, hero, garden and top views).
- `flight_sheet*.png`, `vidcheck_sheet.png`: frames from the two flight videos (`../drone_videos/`).
- `sim_*_start.png`, `sim_*_end.png`: the first and last frames given to OpenArt Wan 3.0 for its videos.
- `sky_sheet.png`, `tex_sheet.png`, `grass_tex.png`: the HDR skies and ground textures that were compared.
